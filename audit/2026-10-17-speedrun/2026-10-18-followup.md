## Corporation: use excess funds for faction milestones before IPO

Bribes provide **reputation immediately**. That reputation contributes to **favor on installation**. The worker can already select a useful augmentation threshold or a donation-unlock threshold; bribes now fund that selected milestone much earlier than the old flat `1e18` reserve allowed.

The new guarded helper reads current corporation funds, investment round, expenses, valuation, and faction reputation, then makes the bribe without an intervening await. This prevents a corporation upgrade from consuming the protected budget between the quote and purchase.

- No bribes during private rounds 1 or 2, preserving Agriculture/Tobacco/Chemical setup.
- From round 3 onward, retain the largest of **90% of current funds**, **ten minutes of expenses**, or **$1 trillion**.
- Spend only when the remaining budget can finish the selected reputation target in full.
- Respect the engine's valuation threshold and actual cash-per-reputation constant.
- A rejected or unavailable bribe falls back to ordinary faction work.
- No IPO is required to bribe. Keep all private funding opportunities and the existing six-city expansion strategy.

For example, a corporation with $20 quadrillion and modest expenses can spend $1 quadrillion on a one-million-reputation gap while retaining $19 quadrillion. The previous $1 quintillion reserve blocked that purchase. This is a policy illustration, not a measured reduction in run time.

Later funding targets and early IPO remain timing experiments. This change obtains the intended reputation benefit without requiring an early IPO or replacing the investment strategy.

## Go: controls, hidden opponent, and observation cost

The normal board-size default stays **13**. New options are applied after the current game finishes, so restarting to change a setting does not deliberately abandon a live board:

```text
run go.js --board-size 5 --opponent "Daedalus"
run go.js --board-size 13 --opponent "Illuminati"
run go.js --opponent hidden
```

Stop the existing instance before starting another. `go.js.config.txt` supports the same options for autopilot launches. Supported ordinary sizes are 5, 7, 9, and 13; `--hidden-opponent false` excludes the hidden opponent from random selection. Explicit `--opponent hidden` still selects it when unlocked.

The hidden opponent is `????????????` / w0r1d_d43m0n. **The Red Pill must be installed**, and the engine supplies a fixed **19×19 Bitverse board** regardless of ordinary board size. Its reward boosts the player's hacking-level multiplier. The script now checks installed augmentations before selecting it, instead of randomly provoking an API rejection. If explicitly requested while locked, it plays a normal eligible opponent until the requirement is met.

One combined board-analysis helper replaces five observations when home has sufficient free RAM. It uses 61.6 GB on v3.0.1; the original smaller helpers remain the fallback. The Go manager itself remains 3.5 GB. This changes observation traffic, not move priorities or cheat policy.

Completed-game totals are kept on home in `/data/go-results.json`, grouped by opponent and board size. Resumed games count toward the win record but are excluded from full-game duration totals. Average full-game duration is `durationMs / timedGames`.

### Board-size experiment

Pinned official v3.0.1 rules, legal moves, scoring, and opponent AI; five seeded games per normal opponent, cheats off. Seed base 521; full results in `go-board-size-results.json`.

| Size | Wins | Illuminati | Average moves by both sides |
| --- | --- | --- | --- |
| 5×5 | 20/30 | 0/5 | 21.8 |
| 7×7 | 16/30 | 0/5 | 44.4 |
| 9×9 | 18/30 | 1/5 | 75.3 |
| 13×13 | 24/30 | 2/5 | 166.5 |
| Hidden 19×19 | 2/3 | Separate opponent | 279.0 |

This small sample supports retaining 13×13 for the current pattern bot. It does not establish live win probabilities or rewards per minute. Browser overhead, game tick waits, RPC transport, and cheats were not reproduced; CPU durations are not live game durations.

Smaller boards need fewer moves, so they can earn streak/favor rewards faster when a solver wins reliably. They provide fewer scored nodes per game, and the same komi occupies a larger fraction of the board. Illuminati has 7.5 komi; its special 5×5 difficulty multiplier is **8**, versus **2** on larger boards. Node power also depends on score and streak, and completed losses still earn reduced power. Favor is awarded on every second consecutive win against a faction the player has joined. Therefore neither raw win rate nor games per hour alone measures the best speedrun policy.
